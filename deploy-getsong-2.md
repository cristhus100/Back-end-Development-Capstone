# deploy-getsong-2.png

## Descripción
Captura de pantalla de la vista Topology de OpenShift.

## Qué debe mostrar:
1. Vista: OpenShift Web Console → Developer → Topology
2. Círculo/pod de Mongo en estado "Running" (azul/verde)
3. Nombre de la aplicación: `mongo`
4. Indicador visual de que está funcionando

## Cómo obtenerla:
1. Abrir OpenShift Web Console
2. Ir a Developer view → Topology
3. Ver el pod de mongo funcionando (círculo azul con anillo azul oscuro)
4. Tomar captura de pantalla
5. Guardar como `deploy-getsong-2.png`
