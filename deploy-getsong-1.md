# deploy-getsong-1.png

## Descripción
Captura de pantalla de la vista Developer de OpenShift.

## Qué debe mostrar:
1. Página: OpenShift Web Console → Developer View → Add → Deploy Image
2. Campo "Image name from external registry": `mongo:latest`
3. Namespace/proyecto seleccionado
4. Botón "Create" visible

## Cómo obtenerla:
1. Abrir OpenShift Web Console
2. Ir a Developer view (esquina superior izquierda)
3. Click en "+Add" → "Deploy Image"
4. En "Image name from external registry" escribir: `mongo:latest`
5. Tomar captura de pantalla antes de hacer click en "Create"
6. Guardar como `deploy-getsong-1.png`
